# Contract: 工作台界面与交互

**Version**: 1.0 | **Date**: 2026-11-06

## 1. 布局

一屏两栏，无页面跳转：

```text
┌─────────────────────────────────────────────────────────────┐
│ OryxOS  ● 健康  Agents 1 · Tools 14 · Provider deepseek     │ 状态条
├──────────────┬──────────────────────────────────────────────┤
│ Agent        │  daily-weather                    [新对话][归档]│
│ ┌──────────┐ │ ┌──────────────────────────────────────────┐ │
│ │每日天气 ✓│ │ │ user  今天杭州天气怎么样？                │ │
│ └──────────┘ │ │ assistant 今天杭州 18~27℃，多云…          │ │
│              │ │   ⚙ http_get                             │ │
│              │ │ user  那明天呢？                          │ │
│              │ │ assistant …（等待中 · 已 12s）            │ │
│              │ └──────────────────────────────────────────┘ │
│              │ ┌──────────────────────────────────────────┐ │
│              │ │ 输入消息…                          [发送] │ │
│              │ └──────────────────────────────────────────┘ │
└──────────────┴──────────────────────────────────────────────┘
```

## 2. 状态与交互

| 区域 | 状态 | 行为 |
| --- | --- | --- |
| 状态条 | 加载中 / 健康 / 离线 | 展示 Agent 数、Tool 数、Provider 名；离线时用警示样式，不隐藏 Agent 栏 |
| Agent 栏 | 加载中 / 有 Agent / 空 | 默认选中第一个；空工作区展示创建 Agent 的引导 |
| 消息区 | 欢迎 / 历史 / 等待 / 错误 / 只读归档 | 等待气泡显示「已等待 Ns」；55s 起提示即将超时 |
| 输入区 | 可输入 / 禁用 | 发送中禁用；空白输入在本地拦截；失败后保留文本 |
| 操作区 | 新对话 / 归档 | 新对话先归档活动会话再清空；归档成功后回到空对话 |

## 3. 展示规则

- 用户消息与助手回复以不同气泡样式展示；助手回复保留换行。
- 工具调用以 chips 形式出现在对应 assistant 回复下方，只显示工具名，可重复名去重。
- `historyTruncated=true` 时在消息顶部显示「仅展示最近 100 条」。
- 归档会话只读：消息可见，输入与发送禁用，展示「开始新对话」。
- 错误条展示固定中文提示；可重试错误提供重试入口，且不丢失用户已输入内容。
- 空工作区文案必须给出可执行下一步（例如先运行 `profile create` 或参考演示工作区说明），不能只显示「暂无数据」。

## 4. 可访问性与兼容

- 发送支持 `Enter`，换行使用 `Shift+Enter`；按钮具备可读文本或 `aria-label`。
- 等待状态使用 `aria-live="polite"` 播报，避免读屏用户错过回复。
- 目标为桌面 Chromium/Edge 近期版本；不承诺移动端、国际化、暗色主题。
- 后端不可达时页面 5 秒内给出连接错误状态，禁止无限加载动画。

## 5. 明确不做

- 不提供 Provider/Agent 在线配置、调度、审计、通知渠道、记忆编辑页面。
- 不展示工具参数、工具结果、System Prompt、文件路径或密钥。
- 不实现流式输出、Markdown 富文本渲染、文件上传或多模态输入。
