# 验收指南：会话上下文压缩

以下命令在实现后从仓库根目录运行。使用 JDK 21、Maven Wrapper、回环协议服务和临时 SQLite。测试不读取真实模型密钥。

## 预算与协议

```powershell
./mvnw.cmd -pl oryxos-core,oryxos-provider -am test
```

预期固定首条系统消息和工具顺序。跨时间或记忆变更时动态字段更新。大工具结果的发送副本带裁剪标记，调用 ID、执行次数和原文保持一致。必需内容超限时没有模型请求。

## 固定样本与重启

```powershell
./mvnw.cmd -pl oryxos-boot -am "-Dit.test=ContextCompactionIT" "-Dfailsafe.failIfNoSpecifiedTests=false" verify
```

用固定时钟，向同一会话回放 32 个不同用户轮次。主模型桩每轮发起两次工具调用，返回两份各 6 KiB 的可复现结果，随后给出固定回复。摘要桩使用确定的 384 字节以内文本。第 24 轮后重启。另设失败用例，验证普通摘要失败时可以完成主调用且成功游标不倒退。

基线按当前实现回放，使用相同输入、工具、稳定区和模型桩，采用 20 轮窗口及完整工具结果。记录每次主调用和摘要调用的请求估算单位和输出估算单位。费率使用固定测试费率，输入每单位 2，输出每单位 8，所有输入统一按未命中计费，结果以相对费用表示。应满足 `新累计输入 < 基线累计输入` 且 `新总费用 < 基线总费用`。真实账单验收采用实际用量和费率，并独立记录缓存命中与未命中。

## 全量回归

```powershell
./mvnw.cmd test
./mvnw.cmd clean package
git diff --check
```

预期各命令退出 0。交付记录包含模块测试、集成回放、构建结果及真实模型未测范围。
