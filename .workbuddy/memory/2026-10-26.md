## 修复 GitHub Actions CI 失败（provider realize #1）

- 现象：Build and quality 工作流 verify 任务在「Maven 质量门禁」步骤 6 秒内失败。
- 排查：在临时 worktree 检出 ae4e0d2 本地跑 `./mvnw verify`，15 模块全部 BUILD SUCCESS → 排除代码/测试问题。
- 根因：`mvnw` 以 `100644`（无可执行位）提交。Windows 不保留执行位所以本地正常；GitHub Actions Ubuntu 上 `./mvnw` 报 Permission denied (exit 126)。
- 修复：`git update-index --chmod=+x mvnw`，提交 4302c6b 到 feature/react（仅模式变更，未动其他未提交文件）。
- 经验：本仓库 Windows 环境开发 + Linux CI，新增 shell 脚本时须确认 git 权限位为 100755；CI 触发条件为 push 到 main 或 PR。
- 追加：已添加 .gitattributes（mvnw/*.sh 强制 LF），提交 212181c，防止未来 CRLF 提交破坏 Linux CI。
