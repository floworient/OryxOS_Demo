WHY ORYXOS

不是再造一个聊天机器人，
而是提供 Agent 的运行底座。

框架解决如何编写 Agent，编排平台解决如何画流程。OryxOS 专注运行时：让一组常驻 Agent 共享可靠、可审计的企业基础设施。

01

企业掌控

私有部署，凭证、记忆和执行记录留在企业环境，可接入既有安全与运维体系。

02

统一运行

CLI、Web、企业 IM 与定时任务共享同一个 Agent 运行时和一致的执行语义。

03

开放连接

通过 Provider、MCP 和 Java Tool 连接模型与业务系统，不绑定单一厂商。

RUNTIME CAPABILITIES

一套内核，承载完整 Agent 生命周期

Provider连接云端与本地模型
ReAct掌控推理与工具执行
Memory沉淀会话与长期记忆
Tool安全调用企业能力
Channel统一终端、API 与 IM
Audit记录完整执行链路

ARCHITECTURE

清晰边界，渐进扩展

所有入口收敛到统一执行链路，核心能力通过模块边界解耦。先把单节点运行时做扎实，再面向治理与分布式场景演进。

GET STARTED

一个 JAR，启动 OryxOS

项目当前处于工程引导阶段。你可以构建全部模块、运行 CLI，并启动 Spring Boot 聚合应用。

oryxos / terminal
$ ./mvnw clean package

$ java -jar oryxos-cli/target/oryxos-cli-0.1.0-SNAPSHOT-exec.jar
OryxOS 0.1.0-SNAPSHOT

$ java -jar oryxos-boot/target/oryxos-boot-0.1.0-SNAPSHOT.jar
OryxOS

Built for enterprise-owned agents.
