# 第 24 课 Sandbox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐额外文件根和可读安全拒绝，验证四工具零 IO 与一次持久化审计。

**Architecture:** tool 实现授权和安全结果，boot 绑定配置及集成测试。复用当前批准 Path/URI、Registry、SkillBindingResolver 与 ToolExecutor，core 无需识别具体异常。

**Tech Stack:** JDK 21、Spring Boot 3.5.8、Spring AI 1.1.2/Alibaba 1.1.2.2、SQLite/JPA/Flyway、现有 JUnit/AssertJ/Mockito。

**Spec:** `docs/superpowers/specs/2026-11-01-sandbox-design.md`；`specs/007-sandbox/spec.md`、`plan.md`、`contracts/sandbox.md`。

## Global Constraints

- 不新建/切换分支，不自动提交或推送；当前为 main。
- 无新增第三方依赖、表、Profile 字段、管理 API、容器或热更新。
- 公共 Skill 保护优先于额外根；绑定每次重读；Shell cwd 限 Agent。
- 仅使用批准目标；统一拒绝不可重试；不更改核心审计写入机制、重试和质量阈值。审计输入脱敏与安全错误分开验收，可依据失败测试单独修正。
- 本文件是步骤说明；实施完成 checkbox 仅更新 `specs/007-sandbox/tasks.md`，不维护重复完成状态。

## Review Focus

- 额外根为公共根祖先时 list/grep/glob 不能泄露未绑定 Skill；Task 2 用名称、元数据、正文 canary 固定。
- 公共根缺失或绑定错误时不得回退宽泛放行；Task 2 明确测试。
- 非法目录、符号链接/junction、相邻同名前缀及不存在写入父目录；Task 2 成对验证。
- 原始异常、凭证查询串与内部路径进入错误；Task 1/3/4 检查固定原因、无 cause 和秘密零命中。
- 新异常类型改变 MCP 授权失败分类；Task 4 回归配置失败与纯外部故障分类。
